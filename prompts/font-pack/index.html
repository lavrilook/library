Базовый пак шрифтов с кириллицей

Четыре открытых семейства: Jost, Montserrat, Oswald и Merriweather. Файлы, лицензии и источники в одном ZIP.

Что внутри

Четыре семейства с кириллицей из официального репозитория Google Fonts.

Как пользоваться

Скачай ZIP, распакуй и установи нужные .ttf-файлы.

Для каких задач

Заголовки, карточки, тексты, презентации и оформление сайта.

Условия

SIL Open Font License 1.1. Лицензии каждого семейства включены в архив.

Что внутри

  • Jost — геометрический гротеск для заголовков и коротких текстов.
  • Montserrat — гротеск для заголовков, навигации и карточек.
  • Oswald — узкий шрифт для коротких выразительных заголовков.
  • Merriweather — шрифт с засечками для текста и заголовков.

У всех четырёх семейств проверено наличие кириллических букв. В архиве — переменные шрифты, лицензии OFL.txt и список источников SOURCES.json. Это отдельная открытая подборка, а не исходный смешанный пак.

Как установить

  1. Скачай и распакуй архив.
  2. Открой файл .ttf и выбери установку шрифта в своей системе.
  3. Перезапусти редактор, если семейство не появилось в списке.
  4. Выбери семейство и нужную насыщенность. Если редактор не поддерживает переменные шрифты, используй официальную страницу для выбора другого формата.

Две пары для начала

Oswald для короткого заголовка + Jost для основного текста. Montserrat для заголовка + Merriweather для основного текста. Проверяй читаемость на реальном размере карточки или экрана.

Лицензии

Файлы загружены из официального репозитория Google Fonts. Каждое семейство распространяется по SIL Open Font License 1.1. Лицензия допускает коммерческое использование и распространение при соблюдении её условий. Сохраняй OFL.txt при передаче шрифтов; ограничения на изменение и именование смотри в лицензии каждого семейства.

Архив не включает пробные и коммерческие шрифты из исходной подборки без подтверждённых условий распространения.
